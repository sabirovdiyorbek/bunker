# 🎮 Bunker Bot — Telegram-бот для игры «Бункер»

Полноценный бот-ведущий для настольной игры «Бункер» на **Python 3.11+**, **aiogram 3** и **SQLite (aiosqlite)**.
Бот работает только в группах, ведёт весь игровой процесс автоматически: набор игроков, раздачу карточек
персонажей в личку, объявление катастрофы, раунды с раскрытием характеристик, обсуждение и открытое голосование.

Поддерживаются три языка интерфейса: **русский, узбекский, английский** (настраивается на чат через `/settings`).

## 📁 Структура проекта

```
bunker_bot/
├── bot.py                  # точка входа, запуск polling
├── config.py                # константы (токен, лимиты игроков, тайминги по умолчанию)
├── requirements.txt
├── .env.example
├── database/
│   ├── db.py                 # слой доступа к SQLite (aiosqlite)
│   └── schema.sql             # DDL: chat_settings, user_stats, games
├── handlers/
│   ├── recruiting.py          # /game, /start, /stop, /leave + кнопки набора
│   ├── gameplay.py             # колбэки: выбор характеристики (в ЛС), голосование (в группе)
│   ├── settings.py              # /settings и подменю
│   └── common.py                 # /help, /profile, /start в личке
├── utils/
│   ├── game_state.py           # GameSession, Player, GameManager (состояние в памяти)
│   ├── game_engine.py           # весь игровой цикл (раунды, голосование, финал)
│   ├── game_content.py           # генератор катастроф и характеристик персонажей (3 языка)
│   ├── formatting.py              # форматирование карточек персонажей
│   └── keyboards.py                # inline-клавиатуры
└── locales/
    ├── __init__.py              # функция t(lang, key, **kwargs)
    ├── ru.py / uz.py / en.py     # словари текстов (полностью синхронизированы по ключам)
```

## ⚙️ Установка

1. Убедитесь, что установлен **Python 3.11+**.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
4. Скопируйте `.env.example` в `.env` (или просто задайте переменную окружения) и укажите токен:

   ```bash
   export BOT_TOKEN="123456789:AA...ваш_токен"
   ```

   Либо впишите токен напрямую в `config.py` (переменная `BOT_TOKEN`).

5. **Важно:** отключите Privacy Mode у бота в @BotFather (`/setprivacy` → `Disable`), если хотите, чтобы бот
   мог видеть все сообщения в группе (для команд это не обязательно, но рекомендуется).

6. Запустите бота:

   ```bash
   python bot.py
   ```

   При первом запуске автоматически создаётся файл базы данных `bunker.db` со всеми нужными таблицами
   (создание идёт по `database/schema.sql`, `CREATE TABLE IF NOT EXISTS` — миграции не нужны).

## 🕹 Как играть

1. Добавьте бота в групповой чат, выдайте ему права администратора (нужно для проверки, кто админ чата,
   и корректной работы с сообщениями).
2. `/game` — начинается набор игроков (по умолчанию 60 секунд, настраивается).
3. Игроки нажимают «✅ Присоединиться». Минимум **4**, максимум **8** игроков.
4. Набор завершается по таймеру или командой `/start` от администратора чата (если игроков ≥ 4).
5. Бот проверяет, что у всех игроков открыт личный диалог с ботом — если нет, игрок исключается
   из игры с предупреждением в чате.
6. Всем игрокам в личные сообщения рассылаются карточки персонажей (профессия, пол/возраст, здоровье,
   хобби, фобия, багаж, доп. факт).
7. Бот объявляет случайно сгенерированную катастрофу и информацию о бункере.
8. **Раунд 1**: все игроки автоматически раскрывают профессию.
9. **Раунд 2+**: каждый игрок в личке выбирает, какую характеристику раскрыть (ограничено по времени;
   не успел — характеристика не раскрывается).
10. Обсуждение в группе (по таймеру).
11. Открытое голосование в группе — кнопки с именами игроков, счётчик голосов виден всем.
    Голосовать за себя нельзя. При ничьей никто не выбывает.
12. Игрок с наибольшим числом голосов покидает бункер (его нераскрытые характеристики публикуются).
13. Игра продолжается, пока не останется **2 игрока** — они объявляются победителями, их полные карточки
    публикуются в чат.
14. Статистика (сыгранные игры / победы) сохраняется в БД и доступна через `/profile`.

## 📜 Команды

| Команда      | Описание                                                            |
|--------------|----------------------------------------------------------------------|
| `/game`      | Начать набор игроков в группе                                       |
| `/start`     | Принудительно начать игру, если набрано ≥ 4 игроков (только админ)  |
| `/stop`      | Остановить текущую игру (только админ)                              |
| `/leave`     | Покинуть набор игроков (или выйти из уже начавшейся игры)           |
| `/settings`  | Настройки чата: язык, время набора/обсуждения/голосования (админ)   |
| `/help`      | Показать правила игры                                                |
| `/profile`   | Личная статистика игрока                                             |

## 🧠 Особенности реализации

- **Состояние игры хранится в памяти** (`utils/game_state.py`, `GameManager`) — по одной активной игре на чат.
  Это обеспечивает простоту и скорость; при перезапуске бота активные игры не восстанавливаются (это нормально
  для ботов такого рода — учтите это при деплое, лучше не перезапускать бот во время активной игры).
- **Настройки чата и статистика игроков** хранятся в SQLite и переживают перезапуск.
- **Устойчивость к отсутствию личного диалога**: перед началом игры бот пытается написать каждому игроку
  в ЛС; если сообщение не доставлено — игрок автоматически исключается, а в группе публикуется список
  исключённых с объяснением.
- **Голосование полностью открытое**: каждое голосование обновляет счётчик прямо на кнопках в реальном
  времени, и в чат публикуется, кто за кого проголосовал.
- **Нельзя проголосовать за себя** — проверяется на уровне обработчика колбэка.
- **При ничьей никто не выбывает** — бот сравнивает максимальное количество голосов и, если оно
  набрано более чем одним игроком, раунд завершается без исключения.
- **Молчаливое воздержание**: специальной кнопки «воздержаться» нет — игрок просто не нажимает ни одну
  кнопку голосования, и его голос не учитывается.
- Весь пользовательский текст выводится через функцию `t(lang, key, **kwargs)` из `locales/__init__.py`,
  так что добавление нового языка — это создание нового файла `locales/xx.py` с идентичным набором ключей
  и его регистрация в `locales/__init__.py`.

## 🛠 Возможные доработки

- Хранение активных игр в базе (для восстановления после рестарта бота).
- Кнопка «повторить игру» в конце партии с автосбором тех же участников.
- Более гибкая настройка количества раундов/времени раскрытия характеристики через `/settings`.
